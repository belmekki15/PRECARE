# 🩺 PreCare AI

### AI-Powered Early Preeclampsia Detection

**PreCare AI** is a multidisciplinary **AI group project** focused on the early detection of preeclampsia through Machine Learning.

The project combines clinical and biomolecular data to provide an **early risk assessment** and serves as a medical decision-support tool, helping healthcare professionals identify potential high-risk cases.

### 🧠 Technologies

* Python & Scikit-learn
* Random Forest
* Gradient Boosting
* K-Means Clustering
* Pandas & NumPy
* Next.js / React / TypeScript
* FastAPI
* Tailwind CSS

### 🌐 Project

**Live Demo:** https://pre-care-plateforme.vercel.app/

### ⚠️ Disclaimer

This project is an academic and experimental medical assistant. It is **not intended to replace professional medical diagnosis or clinical judgment**.
